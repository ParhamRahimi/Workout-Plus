# Support

Report reproducible bugs through the repository's GitHub Issues. Include app
version, iOS version, the action that failed, and whether the data is synthetic.
Do not attach real workout backups, progress photos, body measurements, Apple
Health exports, device identifiers, signing profiles, or account credentials.

For a private vulnerability report use the repository's **Security → Report a
vulnerability** flow after private reporting is enabled. If unavailable, do not
publish the details; request a private contact route without sensitive content.

If the app cannot open saved data, do not uninstall it or delete its container.
Logging is disabled to protect the original store. Reopen the app, then seek
support if the error continues. A database issue requires a recovery plan, not
an automatic reset.

Health deletion requires appropriate permissions. Older records with no saved
sample link may need deleting directly in Apple Health. Editing a local log
does not modify an already synced workout in Health.
